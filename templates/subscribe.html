Step by step, including Android
  • Google Calendar — the button opens calendar.google.com and asks whether to add the calendar. By hand: Other calendars → + → From URL → paste the address.
  • Android phones — the Google Calendar app cannot subscribe to a calendar by address; opening the feed on the phone only downloads a file that will never update. Subscribe once from calendar.google.com in the browser (the Google button above works on the phone), and the calendar appears in the app after its next sync.
  • iPhone and Mac — the Apple button opens a subscription prompt. By hand: Calendar → File → New Calendar Subscription → paste the address.
  • Outlook — the button opens Outlook on the web at Add calendar → Subscribe from web with the address filled in; the Outlook phone app picks it up from there.

Do not download the .ics file. A downloaded copy is a snapshot: it will never show a meeting posted after the day you saved it. The buttons and the address above subscribe to the live feed, which refreshes itself.
