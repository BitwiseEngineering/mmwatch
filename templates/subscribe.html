Calendar subscription Works now

The most useful option: meetings appear in the calendar you already use, and update themselves as new notices are published.

On an Android phone? The Google Calendar app cannot subscribe to a calendar by address, and opening the feed on the phone only downloads a file that will never update. Add it once from a computer instead — calendar.google.com → Other calendars → + → From URL → paste the address below. It should reach the phone within a few hours; if it does not, open the Google Calendar app → Settings → MMWatch and switch Sync on.

Google Calendar Apple Calendar Outlook.com Outlook (work or school)

Each button is a shortcut into that service's add-a-calendar step; sign in first if you are not already. If Google ever answers Unable to add calendar - check the url, add it by hand instead: Other calendars → + → From URL → paste the address below. For any other calendar app, subscribe to the same address. It is a live feed, not a file to download:

Step by step for each app
  • Google Calendar — the button opens Google Calendar and asks whether to add the calendar. By hand: Other calendars → + → From URL → paste the address.
  • iPhone and Mac — the Apple button opens a subscription prompt. By hand: Calendar → File → New Calendar Subscription → paste the address.
  • Outlook — Add calendar → Subscribe from web → paste the address. The Outlook phone app picks it up from there.

Do not download the .ics file. A downloaded copy is a snapshot: it will never show a meeting posted after the day you saved it. Subscribing to the address gives you the live feed, which refreshes itself.
